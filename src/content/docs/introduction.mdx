# Welcome to NotesChatAI

NotesChatAI is an AI study assistant that **remembers everything** across sessions. Unlike ChatGPT (which forgets past uploads once a chat ends) or NotebookLM (which isolates knowledge within individual notebooks), NotesChatAI builds a **persistent, unified knowledge base** that grows with you.

## The Problem We Solve

- **ChatGPT**: Upload a PDF → chat → session ends → knowledge gone
- **NotebookLM**: Create notebook → add 50 sources max → can't search across notebooks
- **NotesChatAI**: Upload once → remember forever → search across everything

## Core Philosophy

1. **Your knowledge compounds** — Every document you add makes future answers better
2. **No artificial limits** — Unlimited documents, unlimited chats, no notebook isolation
3. **Full data ownership** — Export anytime. Self-host if you want. Your data, your rules.
4. **Citations always** — Every answer shows exact source passages. Hover to preview, click to jump.

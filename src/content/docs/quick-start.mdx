# Quick Start

Get up and running with NotesChatAI in under 5 minutes.

## 1. Create an Account

Visit [noteschatai.com/auth/signup](/auth/signup) and sign up with email or Google. No credit card required for the free beta.

## 2. Upload Your First Document

1. Click **"Upload Document"** in the dashboard
2. Drag and drop a PDF, paste a YouTube link, or enter a web URL
3. Wait for processing (usually 10-30 seconds)
4. Your document is now in your knowledge base

## 3. Start Chatting

Go to the **Chat** tab and ask questions:

> "Summarize the key concepts from my machine learning notes"

NotesChatAI will:
- Search your entire knowledge base
- Find relevant passages across all documents
- Generate a cited answer with inline citations
- Show source documents in the sidebar

## 4. Generate an Audio Overview

Click the **Audio** tab → **Generate Overview** → listen to a podcast-style summary with full transcripts and chapters.

## 5. Explore More

- **Mind Maps** — Visualize connections between concepts
- **Flashcards** — Auto-generate spaced repetition cards
- **Quizzes** — Test yourself on any topic
- **Export** — Download as Markdown, Anki, Obsidian, PDF

# Free Beta Guide

NotesChatAI is currently in **free beta**. Here's what you get and what to expect.

## Current Free Beta Limits

| Feature | Limit |
|---------|-------|
| Documents | 50 |
| Chats per day | 30 |
| Audio overviews per day | 2 |
| Storage | 1 GB |
| API access | Not included |
| Support | Community Discord |

## What's Included

✅ **All core features:**
- Persistent knowledge base (no notebook isolation)
- Global semantic search across all documents
- Cross-document citations with hover preview
- Audio overviews with transcripts & chapters
- Interactive mind maps
- Flashcards with FSRS spaced repetition
- Quiz generator
- Study planner
- Export to Markdown, PDF, Anki, Obsidian, CSV

✅ **All document types:**
- PDF, EPUB, TXT, MDX
- YouTube videos (via transcripts)
- Web pages
- Audio files (MP3, WAV)

## What's Coming in Pro

- Unlimited documents & chats
- 20 audio overviews/day
- 50 GB storage
- REST + GraphQL API access
- Webhooks
- Self-hosted Docker option
- Priority support

## Beta Timeline

- **Now**: Free beta open
- **Next**: Pro launch (beta users get 3 months Pro free)
- **Following**: Team/Enterprise plans
- **Ongoing**: Free tier remains free forever

## Known Limitations

- Processing large PDFs (>100 pages) may take 1-2 minutes
- YouTube videos without transcripts can't be processed
- Audio overview generation: ~30 seconds per 10 pages
- Mind map generation for >500 entities may be slow
